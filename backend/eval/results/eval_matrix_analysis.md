## 2. カテゴリ別 詳細考察

### 1. 構造化出力 (`structured_output`: JSON抽出・スキーマ遵守)
- **傾向**:
  - `gemini-2.5-flash` および `gemini-2.5-flash-lite` は **94.4%** の高い遵守率を記録し、純粋な JSON 出力指示を正確に遂行しました。
  - `gemini-2.5-pro` (84.7%) は JSON データの中身自体は完全な正解を出力したものの、「Markdown バッククォートを含めない」という指示に対して ` ```json ` で囲んでしまう傾向が見られ、制約減点が発生しました。
  - `gemini-3.5-flash-lite` は **100.0%** でフォーマット制約・スキーマ内容ともに完全一致を達成しました。
- **インサイト**:
  API レスポンス用途など、フォーマット厳格性が求められるシステム連携には Flash / Flash-Lite 系モデルが即座にパース可能な JSON を返しやすく親和性が高いです。

---

### 2. 否定・禁止制約の遵守 (`negative_constraint`: 禁止単語・特定文字除外)
- **傾向**:
  - `gemini-2.5-pro` および `gemini-2.5-flash` は **100.0%** の完全準拠を達成。「特定単語（AI, 人工知能等）を使用しない」「句読点を使わない」などのネガティブプロンプトを確実にガードしています。
  - Flash-Lite 系統 (`2.5-flash-lite`, `3.5-flash-lite`) は約 **88.9%** となり、長文生成時に稀に禁止語が混入するケースが見られました。
- **インサイト**:
  コンプライアンス遵守やブランドセーフティ、厳格なポリシーフィルタリングが求められるシナリオでは Pro や Flash が最も安定した制御力を発揮します。

---

### 3. 複数ステップ推論・論理パズル (`multi_step_reasoning`)
- **傾向**:
  - 複雑な論理矛盾の解決や計算ステップを要するタスクにおいて、モデル間で最も大きなスコア差が生じました。
  - `gemini-2.5-flash-lite` (66.7%) や `gemini-2.5-flash` (50.0%) は途中式の整理により良好なスコアを獲得。
  - 単純な推論プロンプトでは Thinking プロセスが明示されない場合に Pro/Flash でも途中の前提見落としによる失点が見られました。
- **インサイト**:
  推論系タスクでは、プロンプト内で「思考ステップを段階的に記述させる (Chain-of-Thought / CoT)」指示を追加することで、Pro/Flash 系の精度をさらに引き上げることが可能です。

---

### 4. 長文検索・文脈特定 (`long_context_retrieval`)
- **傾向**:
  - Vertex AI の 2.5 世代 (`pro`, `flash`, `flash-lite`) はすべて **100.0%** を記録。数千文字以上の長大なテキストから指定された特定事実・数値を迷わず正確に抽出できました。
  - 3.x 世代初期のモデル (`3.5-flash`, `3.6-flash`) では埋もれた情報の見落とし（Needle In A Haystack の精度低下）が発生していました。
- **インサイト**:
  RAG やドキュメント要約・QA ボットにおいては、Gemini 2.5 世代以降のモデルであれば Lite 版を含め高い信頼性で文脈活用が可能です。

---

### 5. 曖昧な意図への対応 (`ambiguous_intent`: 決めつけ防止・逆質問)
- **傾向**:
  - `gemini-2.5-pro` と `gemini-2.5-flash` が **100.0%** を記録。ユーザーの意図が多義的な場合に、勝手な仮定で回答を作らず、必要な前提条件の確認や選択肢提示を行うスマートな対話が実現できています。
  - Flash-Lite や一部モデルでは、曖昧な指示に対しても一方の解釈で回答を一気に生成してしまう傾向がありました。
- **インサイト**:
  チャットボットのエージェント対話において、ユーザーとの自然な壁打ちや要件定義を行う用途には Flash / Pro の対話判断力が優れています。

## 4. 本プロジェクト (ADK Agent Chat) における推奨方針

1. **デフォルト対話モデルの選定**:
   - **`gemini-2.5-flash` (Vertex AI)** または **`gemini-3.5-flash-lite` (AI Studio)**
   - **理由**: 総合スコア（87.2% / 97.4%）、レイテンシ（2〜6秒台）、JSON/フォーマット遵守の安定性のバランスが極めて優秀。
2. **モデル切り替え機能の活用**:
   - 高度な分析や長文要約、厳格なポリシー制御が必要な場合は `gemini-2.5-pro` を選択可能にする。
   - レスポンス速度とトークンコストを最優先する場合は `gemini-2.5-flash-lite` を選択。
