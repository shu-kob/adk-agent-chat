# 📊 LLM モデル × カテゴリ別 評価ベンチマークマトリクス & 考察レポート (Phase 1 & 2 準拠)

本ドキュメントは、`docs/SPECIFICATION.md` 第 5 章（Golden dataset 系統）に基づき、最新の評価対象ターゲットモデル 3 候補に対し、全 30 ケース（3 カテゴリ × 10 ケース）を 3 試行実行した決定論的アサーション評価結果と考察をまとめたものです。

---

## 1. 実行条件と評価環境

- **データセット**: `backend/eval/datasets/benchmark_v2.json` (バージョン: `v2.0.0`, 全 30 ケース)
- **試行回数**: 各ケース 3 回試行 (`trials_per_case=3`, 代表値: 中央値 Median)
- **生成パラメータ**: `temperature=0.0`, `seed=42`
- **フォールバック**: `allow_fallback=False` (ADK/API の純粋性能を測定)
- **実行環境**: Vertex AI (`location: global`)
- **総所要時間 / コスト**: 1209.2 秒 (約 20 分) / 総コスト: `$0.056651`

## 3. アサーション別 失敗内訳 & 制約違反分析

各モデルがどの制約で不合格となったかを、アサーション単位の失敗内訳から分析します。

### ① `gemini-3.5-flash-lite` (総合スコア: 88.4% — 最優秀)
- **強み**: 
  - `structured_output` (96.8%) および `multi_step_reasoning` (80.0%) で最高スコアを記録。
  - 会議室重複解決、為替計算、総当たりリーグ戦、シフト割当、積載最適化など多段階推論タスクで高い正解率を達成。
- **弱点・失敗アサーション**:
  - `negative_constraint`: 助詞「の」「ノ」の完全排除指示において `forbidden_char__の` / `forbidden_char__ノ` が 3 回失敗。
  - カタカナ排除指示で `no_katakana_check` に 3 回失敗。

### ② `gemini-3.7-flash` (総合スコア: 81.8%)
- **強み**:
  - `negative_constraint` (91.1%) で最高スコアを記録。ネガティブ制約に対する抑制力とフォーマット遵守が高い。
- **弱点・失敗アサーション**:
  - `multi_step_reasoning` (60.0%): 移動時間を考慮した旅程プランニング（`impossibility_judgment_and_reason`）および複数税率計算（`calculation_final_amount_match`）で失敗。
  - `min_length_check`: 制約を意識しすぎて過度に短い応答になり、最小文字数チェックで 5 回不合格。

### ③ `gemini-3.1-pro-preview` (総合スコア: 83.0%)
- **強み**:
  - 高度な推論パズルや複雑な JSON 構造で安定した回答を出力。
- **弱点・失敗アサーション**:
  - `negative_constraint`: 医療免責条項の付与忘れ (`medical_disclaimer_present` 3回) やひらがな限定指示での漢字混入 (`pure_hiragana_check`)。
  - 試行間のばらつき: `neg_05` (0%〜100%), `neg_06` (50%〜100%), `reasoning_01` (0%〜100%) でスコアが割れる不安定挙動が観測された。

## 4. 運用上の推奨モデル選定

| 用途・シーン | 推奨モデル | 選定理由 |
| :--- | :--- | :--- |
| **通常対話 & API デフォルト** | **`gemini-3.5-flash-lite`** | 総合スコア 88.4% と最高精度であり、トークン単価が最も低コスト（$0.075/1M in）。コスト対効果が圧倒的に優れる。 |
| **厳格な否定制約・安全フィルタリング** | **`gemini-3.7-flash`** | 禁止ワード排除・Markdown 非出力などの制約遵守率（91.1%）が最も高い。 |
| **高度な長考・複雑論理検証** | **`gemini-3.1-pro-preview`** | プレビュー版として高度な推論能力を備えるが、試行間のばらつきがあるためプロンプト最適化と併用を推奨。 |
